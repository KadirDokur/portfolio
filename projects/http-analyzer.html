>Http-Packet-Analyzer

A Python-based HTTP traffic analysis tool designed to capture and inspect unencrypted web communications in real time. Built for learning packet analysis, HTTP protocols, and network monitoring fundamentals.

> Features

  • Real-time HTTP traffic monitoring
  • HTTP request and response detection
  • Source and destination IP tracking
  • Automatic traffic logging

> Technologies

  • Python
  • Scapy
  • TCP/IP Networking
  • HTTP Protocol Fundamentals

> Purpose

Developed to better understand how HTTP communication works at the packet level, how network traffic can be captured and analyzed, and how relevant information can be extracted and stored for further investigation.
